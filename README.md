# ⚔️ Kombat Roulette

A simple and customizable tournament draw tool.

**Kombat Roulette** is a web-based random draw application designed to select fighters for tournaments, versus battles, character comparisons and other fun competitions.

The project was built using HTML, CSS and JavaScript, with a dark interface and customizable themes.

## ✨ Features

- **Random Draw:** Select one or two fighters at random.
- **Versus Mode:** Display two selected fighters in a VS layout.
- **Custom Fighter Lists:** Add fighters by pasting a list or typing their names.
- **TXT Import:** Upload `.txt` files to automatically import fighters, one per line.
- **Individual Removal:** Remove specific fighters from the list whenever needed.
- **Draw History:** Keep track of previously selected fighters.
- **Repeat Control:** Choose whether previously selected fighters can be drawn again.
- **Custom Themes:** Choose between Red, Orange, Green, Light Blue, Purple and Yellow.
- **Language Selection:** Switch between English and Portuguese.
- **Fullscreen Mode:** A dedicated layout for screen recording and presentations.

## 🚀 How to Use

1. Add fighters by typing or pasting their names, one per line.
2. Alternatively, import a `.txt` file containing your fighter list.
3. Select the draw mode: one fighter or two fighters.
4. Click **DRAW** and let the roulette choose!

You can also enable or disable repeated fighters, change the theme and switch languages whenever you want.
